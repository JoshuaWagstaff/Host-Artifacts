# Nightfall refinement C

Runtime feedback pass for Eternal Skies: Nightfall. Fixes Duskborn wing rendering, rebuilds the Duskborn around a fully rendered hierarchical celestial model with 2x texture density, refines face/clothing/wing pixel art, slows and telegraphs flight/Veil behavior, lowers combat pressure, moves Nightfall mobs into Aether-native mob categories, and reduces Duskborn spawn pressure. Stormling damage/knockback are slightly toned down while preserving its island-edge hazard role.
